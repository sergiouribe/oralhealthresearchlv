## Technical notes

- **Cropping:** every image is cropped to fill its frame (center crop). Keep faces and key content away from the edges.
- **Black and white:** photographs (2 to 5) are displayed in grayscale by the design. Supply color files; the page converts them.
- **Chart (1) and timeline (6):** the grayscale filter also applies, so use PNGs that read well without color, or tell the designer to disable it for these two.
- **File size:** keep each file under 400 KB. Photos: JPG quality 75 to 80. Use squoosh.app or tinypng.com to compress.
- **Resolution:** the sizes above are 2x the displayed size, so images stay sharp on high-density screens.
- **Filenames:** lowercase, no spaces. The names are case sensitive on GitHub Pages.
- **Rights:** use only images you own or have permission to publish. Get consent for portraits of people.
